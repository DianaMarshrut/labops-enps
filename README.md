# labops-enps — eNPS: опрос удовлетворённости сотрудников

Капсула даёт готовую анкету и текст приглашения. Ты создаёшь форму сам (5–7 минут),
собираешь ответы — капсула считает eNPS, группирует темы и даёт 3 действия на месяц.

**Что получаешь:**
- Анкета eNPS (5 вопросов) + текст приглашения для команды.
- Инструкция: создать форму в Google Формах, Яндекс Формах или Битрикс24.
- После сбора ответов: индекс eNPS, темы, 3 конкретных действия.
- HTML-отчёт для хранения и показа.

**Что такое eNPS.** Индекс лояльности сотрудников — доля сторонников (оценки 9–10)
минус доля критиков (0–6) на вопрос «Готов рекомендовать нашу компанию как место работы?».

## Как поставить

### Claude Code

```
/plugin marketplace add DianaMarshrut/labops-enps
/plugin install enps@labopsai-enps
```

Напиши: **«eNPS»**.

### Claude (claude.ai, приложение)

1. Настройки → Коннекторы и плагины → Маркетплейс.
2. Вставь ссылку: `https://github.com/DianaMarshrut/labops-enps`
3. Установи плагин «enps».
4. Напиши: **«eNPS»**.

### Codex

```
codex plugin marketplace add DianaMarshrut/labops-enps
```

Через `/plugins` → Install → напиши: **«eNPS»**.

### ChatGPT (через проект)

1. Создай проект «eNPS» в ChatGPT.
2. Загрузи файл `chat-instruction.md` в файлы проекта.
3. Напиши: **«eNPS»**.

## Откуда берём ответы

| Вариант | Как работает |
|---|---|
| Google Формы → Google Таблица | Коннектор Google Drive в настройках чата, или экспорт CSV |
| Яндекс Формы | Экспорт Excel/CSV → загрузи файлом |
| Битрикс24 опросы | Экспорт Excel → загрузи файлом [проверить MCP] |
| Typeform, SurveyMonkey, Тестограф | Экспорт CSV → загрузи файлом |

## Ограничения

- Менее 5 ответов — капсула предупредит о малой выборке.
- Анонимность: в отчёте нет имён и не раскрывается авторство.
- Сам сервер для сбора ответов не включён — используй готовые формы.

## Команды

| Команда | Что делает |
|---|---|
| `eNPS` | Выдать анкету и инструкцию по созданию формы |
| `Посчитай eNPS` | Считать по готовым ответам |
| `Обнови отчёт` | Пересчитать по новым данным |
